# Evidence

`final/` contains the authoritative evidence for the current release candidate:
full pytest, release verification, Waitress smoke, benchmark, and a concise release summary.
The current target is ClassShift `1.0.0rc8`.

`history/` preserves earlier attempts, audits, and RC6/RC7 evidence for transparency.
Historical failures or dependency blockers are not evidence about the current release.

Evidence from a test double is explicitly labeled and is never presented as real OR-Tools execution.
A PASS in a subset is not a substitute for full release verification.
